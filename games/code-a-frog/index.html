Hop can only follow instructions, one step at a time. Write a program to guide Hop across the lily pads to the fly!

Pick your coding skill

Tap the arrows to add steps to your program, then press Run. If Hop lands in the water, find the step that went wrong and fix it. That is called debugging! In the Loops level you have only a few blocks, so tap a block to make it repeat 2, 3, or 4 times.
